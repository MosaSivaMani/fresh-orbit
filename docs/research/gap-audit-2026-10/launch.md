# Gap audit: launch readiness outside the screens (2026-10-29)

Author: launch-readiness reviewer. Scope: `infra/`, `.github/workflows/`, `docs/runbooks/`, environments and secrets,
backups and restore drills, Render demo vs. real hosting (D127), Indian compliance and store requirements, payments,
e-mail/SMS, sample data in Production (rule 16), domain/DNS, and what the owner still has to give (§6 of
`docs/team/next-steps.md`). Read-only review of `main` at `5e0907d`; nothing was built, run or deployed. GitHub
settings were read with `gh api` (read-only). **Not legal advice**: legal rows say what the repo shows and what the
drafts in `docs/legal/` already flag; a lawyer and the CA confirm.

## Summary

The deploy machinery is in good shape: one compose file with pinned images, memory limits, log rotation, non-root
containers, Caddy with automatic TLS and strict headers, a deploy script with pre-deploy backup and automatic
rollback, nightly encrypted offsite backups with a scripted restore drill, and server hardening. Sample data is
refused in Production (`MigrationRunner.cs:22`), the Fake payment gateway is refused in Production
(`ProviderCatalog.cs:35-41`) and the Demo host refuses any database that is not the demo's. **None of it has run on a
real server yet**, and no server, domain, GitHub deploy environment or offsite bucket exists.

What stops a legal, safe launch today: no domain or production server; DLT registration not done (the Api and Worker
refuse to start without it); no GSTIN or FSSAI licence saved (invoices are refused, delivered orders dead-letter);
the website does not show the legal name, address, GSTIN, FSSAI number or a grievance officer; the policy pages are
outlines and the lawyer has not reviewed `docs/legal/`; and offsite backups are not set up. Next come repository
hygiene on a now-public repo (no branch protection, secret scanning off), silent fall-backs that break rule 7 (e-mail
and push only logged in Production), the Android release (debug signing, default Flutter icon and splash, no store
assets, no data-safety answers), and no alerting unless the optional monitoring profile is switched on.

Counts: **Blocker 10 · High 23 · Medium 26 · Low 37** (96 gaps), plus 40 missing features and details in the second
table.
