# Prompts: website home pictures (2026-10-28)

The website home needs six pictures to match the owner's reference (`design/mockups/web-home-reference-owner.png`;
D247, D248). Each prompt below is the slot's `prompt` in `packages/illustrations/manifest.json`. It is built from the
scene, the style block, the background and the shape (`illustrations.md` §2), and it ends with the no-text line.
Paste one prompt, unchanged, into an image tool whose licence allows commercial use.
